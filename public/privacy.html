2. Dati Trattati e Finalità

Pwnify tratta esclusivamente i dati necessari all'erogazione del servizio di formazione:

  • Dati di Autenticazione: indirizzo email, identificativo utente e token di sessione ottenuti tramite accesso con Google o GitHub (OAuth), oppure una sessione ospite salvata solo sul dispositivo.
  • Profilo: Callsign (nome pubblico) ed eventuale bio scelti dall'utente.
  • Progressi di Formazione: punti XP, punteggio ELO, nodi e laboratori completati, streak giornaliero e cronologia dei duelli.
  • Dati Tecnici: versione dell'app e identificatori tecnici necessari alla sincronizzazione dei progressi. Gli eventi diagnostici sugli aggiornamenti restano memorizzati in locale sul dispositivo.

Base giuridica: esecuzione del servizio richiesto dall'utente (art. 6.1.b GDPR) e, per i pagamenti, adempimento di obblighi contrattuali e fiscali.

3. Accesso con Google e GitHub

Quando accedi con Google o GitHub, Pwnify riceve solo i dati minimi del profilo autorizzati: indirizzo email, nome profilo/username e identificativo dell'account presso il provider. Questi dati servono a creare l'account, sincronizzare i progressi e mostrare il tuo Callsign.

Google API Services User Data Policy:

Pwnify's use and transfer to any other app of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. I dati non vengono ceduti a terzi né utilizzati per l'addestramento di modelli di intelligenza artificiale.

4. Acquisti e Checkout (Polar)

Gli abbonamenti a pagamento (Pwnify PRO) sono gestiti da Polar Software, Inc. (polar.sh), che opera come Merchant of Record indipendente per pagamento, fatturazione e imposte. All'apertura del checkout Pwnify trasmette a Polar solo l'indirizzo email e l'ID del tuo account, per associare l'abbonamento al tuo account. Polar ci comunica lo stato dell'abbonamento (attivo, annullato, revocato) per attivare o disattivare PRO.

Pwnify non riceve e non memorizza numeri di carta o coordinate bancarie: questi dati sono trattati esclusivamente da Polar e dai suoi fornitori di pagamento.

5. Duelli Peer-to-Peer (WebRTC) e Indirizzo IP

Le sfide 1v1 nella Arena usano WebRTC per collegare direttamente i due dispositivi.

Visibilità dell'indirizzo IP: durante una connessione diretta peer-to-peer l'indirizzo IP pubblico del tuo dispositivo è visibile all'avversario, salvo quando la rete impone il passaggio attraverso un server relay TURN.

6. Fornitori Terzi

  • Supabase Inc.: autenticazione, database (PostgreSQL) ed Edge Functions.
  • Vercel Inc.: hosting dell'applicazione web.
  • Google LLC e GitHub Inc.: accesso tramite OAuth; Google fornisce inoltre server STUN pubblici per la connessione WebRTC.
  • Polar Software, Inc.: checkout, pagamenti, fatturazione e gestione dell'abbonamento PRO.
  • Metered: credenziali temporanee e relay TURN per WebRTC.
  • PeerJS Cloud (0.peerjs.com): server di segnalazione per avviare le sessioni WebRTC.

Alcuni fornitori hanno sede negli Stati Uniti; il trasferimento avviene sulla base delle garanzie previste dal GDPR (es. clausole contrattuali standard o EU-US Data Privacy Framework).
